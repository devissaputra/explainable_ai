# Data

This project uses scikit-learn's Wisconsin Diagnostic Breast Cancer dataset.

- 569 observations
- 30 numerical features
- binary target
- stratified 75/25 train/test split

Source documentation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html

The feature names supplied with the dataset are kept so permutation-importance results can be reported in readable form.
